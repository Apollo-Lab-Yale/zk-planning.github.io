Towards Zero-Knowledge Task Planning via a Language-based Approach

Liam Merz Hoffmeister1, Brian Scassellati1, Daniel Rakita1,
1Yale University
Paper arXiv Video Code Full Chat Interaction

An LLM-based framework for Zero-Knowledge task planning, utilizing sub-modules for task interpretation, goal decomposition, and behavior tree generation, with a refinement loop for dynamic adjustments during execution.

Abstract

We introduce and formalize the Zero-Knowledge Task Planning (ZKTP) problem, i.e., formulating a sequence of actions to achieve some goal without task-specific knowledge. Additionally, we present a first investigation and approach for ZKTP that leverages a large language model (LLM) to decompose natural language instructions into subtasks and generate behavior trees (BTs) for execution. If errors arise during task execution, the approach also uses an LLM to adjust the BTs on-the-fly in a refinement loop. Experimental validation in the AI2-THOR simulator demonstrate our approach's effectiveness in improving overall task performance compared to alternative approaches that leverage task-specific knowledge. Our work demonstrates the potential of LLMs to effectively address several aspects of the ZKTP problem, providing a robust framework for automated behavior generation with no task-specific setup.

Zero-Knowledge Task Planning Problem

We formalize the Zero-Knowledge Task Planning (ZKTP) problem as follows:

Zero-Knowledge task planning refers to the process of generating a sequence of actions, denoted by π = [a1, a2, . . . , an], to successfully achieve a given goal, G, without relying on any prior knowledge specific to the task at hand. The only permissible information available to the agent in Zero-Knowledge task planning is task-agnostic and remains fixed and invariant across all potential tasks.

This problem definition disallows:

  • Task-specific predicates or instances (objects)
  • Environmental models (e.g., maps, object locations)
  • Prior task-specific knowledge or experience
  • Fine-tuning of a model based on task-specific data

The key challenge is that the agent must bootstrap a strategy on-the-fly, relying solely on real-time interpretation of the instruction and sensory inputs from the environment during task execution.

Methodology

Our approach comprises two high-level components:

1. Natural Language Planning Engine

The Natural Language Planning Engine interprets user requests, converts them into structured task representations, and manages the entire planning process. It consists of three sub-modules:

Task Interpretation

Interprets natural language instructions and gathers environmental context through robot sensors.

Goal Decomposition

Breaks down tasks into smaller sub-tasks with completion conditions using General Predicates.

Action Planning

Generates Behavior Trees in XML format to sequence actions for completing each sub-task.

2. Refinement Loop

The Refinement Loop oversees the execution of planned actions and adapts them based on real-time feedback from the environment. It can be triggered by:

  • General Errors: notClose, notVisible, doesNotExist
  • Goal Condition Failures: When a sub-task completes but its goal condition is not satisfied

When errors occur, the LLM modifies the current Behavior Tree to guide successful execution, incorporating detailed feedback and environmental context.

Experimental Results

We evaluated our approach on four household tasks in the AI2-THOR simulator, comparing against four baselines: SMART-LLM, MLDT, BCR, and our approach without the refinement loop.

Task Success Rates

Method Apple in Fridge Soak Mug Set Table Coffee to Table

Our approach achieves competitive performance while requiring zero task-specific knowledge, highlighting its suitability for uncertain and novel scenarios. The refinement loop proves critical for complex tasks, significantly improving success rates.
